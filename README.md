# Project UserListApp - Test-1-COP4656E-301

Submitted by: Carlita Coleman

Time spent: 10 hours spent in total

## Summary

UserListApp is an android app that covers  RecyclerView + API Integration. 

Objective:

Build an Android app that fetches data from a public REST API and displays 
the results in a RecyclerView. The app should show dynamic content 
loaded from the internet (not hardcoded).
